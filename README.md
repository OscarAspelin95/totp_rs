# totp_rs

🚧 Work in progress

Project for local TOTP authentication. The goal is to have a running Axum web server with a Turso database that stores the secrets (which is wayyy to overkill for a local project) and a TUI application for managing paswords.

## Tech stack

- [Axum](https://github.com/tokio-rs/axum)
- 🚧 [Ratatui](https://github.com/ratatui/ratatui)
- 🚧 [Turso](https://github.com/tursodatabase/turso)
